# tqdmxx

A feature-rich Python progress bar library with rich features, supporting multiple styles and multilingual display.

## Features

- 14 different styles of progress bars
- Bilingual support for both Chinese and English
- Automatic detection of system language
- Support for customizing color, width, and update interval
- Display of processing rate and estimated remaining time
- Smooth animation effects to reduce flickering

## Installation

```bash
pip install tqdmxx
```
